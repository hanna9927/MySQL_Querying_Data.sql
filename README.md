# MySQL Querying Data Overview

This project demonstrates SQL data querying and analysis using MySQL. It covers commonly used SQL clauses, aggregate functions, grouping, filtering, updating data, and joins using an Employee Database.

## Topics Covered

* DISTINCT
* Column Aliases
* WHERE Clause
* Comparison and Logical Operators
* IS NULL
* LIKE
* UPDATE
* ORDER BY
* LIMIT
* Aggregate Functions

  * SUM()
  * MIN()
  * MAX()
  * AVG()
  * COUNT()
* GROUP BY
* HAVING
* INNER JOIN
* LEFT JOIN
* RIGHT JOIN
* Database Operations

## Database Operations

The queries were used to:

* Find distinct employee salaries
* Rename columns using aliases
* Filter employees based on salary and joining date
* Identify employees with missing designations
* Update missing employee designations
* Sort employees by department and salary
* Retrieve a limited number of records
* Calculate salary and age statistics
* Analyze salaries by location and designation
* Find departments with fewer than 3 employees
* Filter grouped results using HAVING
* Combine employee, department, and location data using joins
* Count employees in each department
* Display employee and location information
